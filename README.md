# MovilUP Chile

## Sprint 01 / V1.3 — proyectos reales + catálogo de upgrades

Frontend Flask/Jinja2 mobile-first para MovilUP Chile.

### Incluye
- Identidad Automotive Tech Premium.
- Home responsive.
- Servicios.
- Historia desde 2018.
- Galería de trabajos reales.
- Proyecto Chery Tiggo (2019).
- Proyecto Mazda CX-9 4x4 (2026): cambio de radio original por Android 9".
- Proyecto Volkswagen Gol (2026): instalación de radio 2 DIN Bluetooth.
- Catálogo visual de productos y soluciones.
- Accesorios y biseles/adaptadores como parte del concepto de upgrade integral.
- Imágenes de referencia de audio, seguridad, TPMS, LED y retrovisores aportadas para el catálogo.
- Flujo visual inicial de cotización.
- Rutas básicas funcionales.

### Ejecutar
```bash
pip install -r requirements.txt
python run.py
```

Luego abrir `http://127.0.0.1:5000/`.
